# RapScript RO

Generator de cuvinte random în **limba română** pentru antrenament de freestyle rap. Un cuvânt mare pe ecran, care se schimbă la un interval ales - tu îl țeși în rimă.

Inspirat de [rapscript.net](https://rapscript.net) (există din 2008, 6 limbi cu word bank real pe web - româna nu e printre ele). RapScript RO umple golul ăsta, cu un word bank românesc adevărat.

## Stadiu

🚧 În construcție. Proiect de învățare web dev, cap-coadă. v1 = "inima":

- [ ] Generator de cuvinte RO random
- [ ] Viteză reglabilă (interval între cuvinte)
- [ ] 3 niveluri de dificultate (începător / avansat / profesionist)
- [ ] Play / pause + fullscreen
- [ ] Deploy live

Faze viitoare: beat player, înregistrare freestyle, moduri tematice, sync pentru cyphere.
